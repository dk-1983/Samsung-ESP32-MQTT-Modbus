# Samsung-ESP32-MQTT-Modbus — информационный лист регистров

Производитель контроллера: **4vrs**. Прошивка: **0.5.0**. Версия карты: **0.3.0**.

ESP32 переводит Modbus TCP/RTU в D0 UART кондиционера Samsung. Совпадающие основные
функции используют адреса MIM-B19N/B19NT; дополнительные функции контроллера размещены
с адреса 2450. Один контроллер обслуживает один внутренний блок (IU0).
Все адреса ниже десятичные, от нуля. R — чтение, W — запись.

## Граница заводской карты Samsung и расширений 4VRS

**2449 — конец заводского диапазона внутренних блоков MIM-B19N/B19NT.
2450 — начало наших дополнительных регистров 4VRS.**

Это граница диапазона внутренних блоков, а не всей адресации Samsung:
заводские служебные MessageSet 6000/7000 остаются отдельно и здесь не реализованы.

| Адреса PDU | Происхождение / назначение | Что реализовано в Samsung-ESP32 |
|---|---|---|
| 50–99 | Заводская карта Samsung, внутренний блок IU0 | 50–55, 57–59; подробности ниже |
| 100–2449 | Заводской диапазон остальных внутренних блоков IU1–IU47 | Зарезервирован; наш контроллер обслуживает один блок IU0 |
| **2450–2474** | **Начало расширений 4VRS** | Дополнительный каталог UART-параметров |
| 2475–2483 | Расширения 4VRS | Диагностика, свежесть данных, результаты команд |
| 2484–2487 | Расширения 4VRS | Обе оси жалюзи, пресеты, полная скорость с Turbo, Quiet |
| 2488–2499 | Резерв 4VRS | Не назначены |
| 2500–2949 | Расширения 4VRS | Полные raw-ответы каталога, длина и возраст данных |

Совпадение адресов основных функций с Samsung не означает полную эмуляцию
заводского адаптера: особенности данных 50/51 и проверки свежести описаны ниже.
Неназначенные адреса не являются читаемыми регистрами с нулевым значением.

## Подключение и адресация

| Параметр | Значение |
|---|---|
| Modbus TCP | Порт 502, адрес контроллера настраивается пользователем |
| Modbus RTU | 9600 бод по умолчанию, 8 бит, Even, 1 стоп-бит |
| Возможные скорости RTU | 9600, 19200, 38400, 57600, 115200 |
| Slave / unit ID | По умолчанию 1, настройка 1–247; используется и для TCP |
| Чтение | FC03 holding или FC04 input — одинаковая карта чтения |
| Запись | FC06 одного holding-регистра, FC16 нескольких |
| Coils | Нет: FC01/05/15 возвращают exception 01 |
| Настройка транспортов | `http://<IP>/modbus`, независимые checkbox RTU/TCP |

Транспорты по умолчанию выключены, включаются владельцем. С прошивки 0.4.2 UART включён при каждой загрузке; локальный
выключатель UART остаётся. В 0.4.0–0.4.1 требовалось включать UART после перезапуска.
Сохранение MQTT-настроек в 0.4.2 перезагружает плату, что кратковременно прерывает Modbus.

**Все адреса далее — десятичные, zero-based PDU. Ничего не прибавлять.**
Например, адрес 52 передаётся как 52 (0x0034). В интерфейсе с one-based нотацией
он может называться 53 или 40053. Не передавать 40053 в PDU.
IU0 фиксирован и не зависит от unit ID. Формула заводского диапазона:
`50 + 50*IU + offset`, IU=0..47. Его конец — 2449; расширения начинаются с 2450.

## Регистры по заводской карте Samsung — IU0

Один регистр = 16 бит. По сети старший байт идёт первым. Все слова unsigned,
если явно не указан signed int16.

| PDU | Доступ | Тип / масштаб | Назначение |
|---:|---|---|---|
| 50 | R | uint16 enum | Связь: 0 — нет полного свежего состояния; 7 — готов; 11 — есть известные поля, но полный набор не свежий |
| 51 | R | uint16 | Тип блока: 65535 / FFFF, неизвестен; не использовать как модель или идентификатор |
| 52 | R/W | uint16 enum | Питание: 0 выкл., 1 вкл. |
| 53 | R/W | uint16 enum | Режим: 0 auto, 1 cool, 2 dry, 3 fan_only, 4 heat |
| 54 | R/W | uint16 enum | Заводская скорость: 0 auto, 1 low, 2 medium, 3 high; для основной сущности предпочтительнее 2486 |
| 55 | R/W | uint16 bool | Вертикальное качание: 0 выкл., 1 вкл.; запись сохраняет горизонтальное |
| 57 | W | uint16 action | Сброс напоминания фильтра: записать 1; 0 — ничего не делать |
| 58 | R/W | uint16 ×0.1 °C | Заданная температура: 160..300, только кратные 10, то есть 16..30 °C шагом 1 °C |
| 59 | R | int16 ×0.1 °C | Температура помещения, сначала преобразовать two's complement в signed |


При Turbo чтение 54 возвращает **exception 0B**, не 5. Поэтому не включать 54
в обязательный общий блок климатических данных. У 54 и 2486 **разные коды Auto**.
56 не назначен; 57 нельзя читать. Запрос 52..59 целиком не работает.

Режим 53 не меняет питание 52. Одновременное включение и выбор режима выполняется
FC16 по адресу 52 с двумя значениями `[1, mode]`. Для отключения достаточно 52=0.
Quiet 2487 и preset 2485 относятся к одному полю; их нельзя писать одним пакетом.

## Дополнительное управление 4VRS — 2484–2487

Эти адреса разработаны для Samsung-ESP32 и не относятся к заводской карте Samsung.

| PDU | Доступ | Тип / масштаб | Назначение |
|---:|---|---|---|
| 2484 | R/W | uint16 enum | Полное качание: 0 off, 1 vertical, 2 horizontal, 3 both |
| 2485 | R/W | uint16 enum | Preset: 0 none, 1 boost, 2 sleep, 3 quiet, 4 legacy smart, 5 legacy soft cool, 6/7/8 legacy wind 1/2/3 |
| 2486 | R/W | uint16 enum | Полная скорость UART: 1 low, 2 medium, 3 high, 4 auto, 5 turbo |
| 2487 | R/W | uint16 bool | Quiet: 1 включает preset=3; 0 снимает quiet, но сохраняет другой активный preset |

## Подтверждение команд и доступность

Modbus-положительный ответ — команда принята, **не доказательство выполнения**.
Не переключать отображаемое состояние оптимистично. Состояние получается от AC.
Ответ UART на запись тоже не равен фактическому изменению состояния.

- Свежесть чтения отдельного поля — менее 30 секунд.
- Для записи требуется UART включён, отсутствие pending-команды и свежие основные
  поля/затрагиваемые поля менее 10 секунд.
- Основные поля CORE: питание, уставка, режим, скорость. Температура комнаты,
  качание и preset могут отсутствовать отдельно; наличие CORE не гарантирует их.
- Основной UART-опрос идёт примерно каждые 5 секунд. Modbus читает кэш, не запускает
  немедленный UART-опрос каждого запрошенного регистра.
- Pending-команда завершается по обратной связи либо через 10 секунд таймаутом.
- Общий UART ресурс один: команды Modbus, MQTT и веб-пульта могут конфликтовать по busy.

Записи выполняются последовательно. После записи проверять
результат и целевые поля; не считать старое result=2 подтверждением новой команды.
Нет отдельного Modbus transaction ID для UART-команды: при нескольких управляющих
клиентах подтверждение имеет ограничения. Не повторять автоматически кнопки сброса.

| Exception | Значение | Обработка ответа |
|---|---|---|
| 01 | Неподдерживаемая функция | Исправить FC, не повторять бесконечно |
| 02 | Неназначенный адрес / запрещённый доступ | Исправить адрес или разбить диапазон |
| 03 | Недопустимое значение/пакет | Не округлять и не повторять без изменения |
| 06 | Busy, UART выключен или передача сейчас невозможна | Ограниченный отложенный повтор обычной команды; проверить 2480 |
| 0B | Нет свежего/представимого состояния | Поле unknown/unavailable; не подставлять ноль |

Ошибка 0B относится к запрошенным данным, а не ко всем функциям контроллера.
Сохранение последнего значения возможно только с пометкой недостоверности, а не
как актуальное измерение. При отсутствии свежего CORE климат не считать готовым.
При потере TCP/RTU делать недоступным устройство; диагностика 50/2479 позволяет
отличить ответ контроллера от свежей связи с кондиционером.

Особенность совместимости: неверные значения 52–55 подтверждаются и игнорируются
(UART-команда не отправляется). Проверять диапазоны на стороне UI обязательно.
Неверная уставка 58, включая дробный шаг, возвращает 03.

## Диагностические регистры 4VRS — 2475–2483

| PDU | Значение |
|---:|---|
| 2475 | Возраст последнего core status frame в секундах, saturate 65535; 65535 также «никогда» |
| 2476 | Младшее слово счётчика core status frames |
| 2477 | Старшее слово счётчика; total = reg2476 + (reg2477 << 16) |
| 2478 | Последний результат основной команды: 0 idle, 1 pending, 2 confirmed, 3 timeout/unconfirmed, 4 cancelled |
| 2479 | Биты: 0 CORE fresh, 1 RTU enabled, 2 TCP enabled, 3 UART TX enabled |
| 2480 | UART TX enabled 0/1, только чтение |
| 2481 | Результат extended: 0..4 как выше, 5 acknowledged/unverified action |
| 2482 | Последний extended index 0..24; 255 если не было |
| 2483 | Размер каталога: 25 |

2475 — возраст кадра, не гарантия свежести всех его полей. Счётчик 32-битный,
порядок слов **low, high**, не обычный high, low. В пределах слова порядок байт
стандартный Modbus. 2480 нельзя использовать как Modbus-switch с записью.
Включение extended polling тоже не имеет Modbus-регистра.

## Каталог расширений 4VRS — 2450–2474

Однобайтовый регистр `2450 + index` читается только при свежем значении длиной
ровно один байт. Иначе 0B. Для многобайтовых ответов использовать raw-блок ниже.
У всех строк есть raw-обратная связь, но это не обещание, что конкретная модель
вернёт значение. Названия legacy взяты из разобранного UART-протокола.

| 1 | 2451 | 13/32 | Auto clean | 34 enabled, 35 disabled |

| 3 | 2453 | 13/40 | Energy setting raw | 0..255, шаг 1; единицы не установлены |
| 4 | 2454 | 13/44 | Reset filter reminder | Только 0; action |
| 5 | 2455 | 14/E9 | Filter interval legacy | 0..4; UI-метки 0/180/300/500/700, единицы не подтверждены |
| 6 | 2456 | 14/E8 | Reset usage counters | Только 1; action |
| 7 | 2457 | 12/74 | Beep raw | Нет |

| 10 | 2460 | 13/77 | Cooling capability raw | Нет |

| 21 | 2471 | 12/01 | Control enable raw | Нет |
| 22 | 2472 | 14/37 | WiFi status raw | Нет |
| 23 | 2473 | 14/38 | Internet status raw | Нет |
| 24 | 2474 | 12/63 | Airflow direction legacy | 18,33,49,65,81,97,113,129,130,146,162,178,194 |

Для 2474 метки текущего веб-пульта по порядку: Off, Indirect, Direct, Center,
Wide, Left, Right, Long, Legacy vertical 82, Vertical, Horizontal, Both, Fixed.
Это экспериментальный raw select. Для обычного swing использовать **2484**:
на испытательном блоке остановка качания проверена через raw C2=194;
legacy Off=18 не заменяет проверенное выключение через нормализованный регистр.

Кнопка фильтра: либо заводской action **57=1**, либо raw action **2454=0**,
не обе команды. 57 не имеет читаемого состояния. Чтение raw 2454 при наличии
байта не означает, что сброс выполнен. Результат 2481=5 означает только ACK
действия без доказанного сброса счётчика/напоминания.

Физические единицы raw-параметров не подтверждены: значения Power, Energy, Runtime,
Outdoor temperature не являются готовыми измерениями W, kWh, часов или °C.
FE/FC/FF — реальные байты ответа; не трактовать автоматически как «нет ошибки»,
отрицательную температуру или unsupported.

## Raw-блоки 4VRS — 2500–2949

Для каждого index 0..24 начало `B = 2500 + 18*index`:

| Offset | Содержимое |
|---:|---|
| 0 | Длина полезных данных, до 32 байт |
| 1..16 | По два исходных байта в слове, первый байт в старших 8 битах |
| 17 | Возраст в секундах, saturate 65535; неизвестное значение тоже 65535 |

Например, index 8 (ошибки): B=2644, данные 2645..2660, возраст 2661.
Index 24: B=2932, данные 2933..2948, возраст 2949.
Декодирование: для каждого слова `[word >> 8, word & 255]`, обрезать массив по длине.
Не менять порядок слов, не декодировать версии/модель как число или ASCII без проверки.

Возраст читается даже при устаревших/неизвестных данных. Остальные слова такого
блока возвращают 0B при устаревании; весь групповой запрос тогда тоже завершается
ошибкой. Для надёжной диагностики читать возраст отдельно от payload. Не опрашивать
все 450 слов одним диапазоном и не объединять разные raw-блоки в обязательный запрос.

**Extended status polling по умолчанию выключен даже в 0.4.2.** В веб-пульте
его можно включить локально; есть кнопка разового чтения extended. Modbus не включает
опрос автоматически. При включении каталог обходится по одному элементу с интервалом
не менее 800 мс, с приоритетом core/служебных обменов, поэтому отдельные значения
могут устаревать. Это ожидаемая причина 0B, а не повод скрывать весь Device.

## Ограничения пакетных запросов

FC16 максимум 8 слов. Вся последовательность сначала валидируется, затем
отправляется одна UART-команда. Нельзя смешивать core и extended, несколько extended,
или разные адреса одного и того же нормализованного поля. FC16 — только непрерывные
адреса: нельзя передать «разреженную» карту. Для расширений предпочтителен FC06.
Пакет 2484..2487 неверен, поскольку preset 2485 и quiet 2487 оба меняют PRESET.
Между запросами выдерживается не менее 10 мс.

Неназначенные 56, 60.., 2488..2499 и прочие пробелы не заполнять нулями.
Регистр 69..71 заводского адаптера относится к ERV, не нашему fan_only;
78 — quiet гидромодуля, для нашего quiet использовать 2487.
Не использовать заводские MessageSet 6000/7000: наш контракт их не реализует.

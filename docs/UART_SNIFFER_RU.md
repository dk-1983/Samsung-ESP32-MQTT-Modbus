# Пассивный двухканальный UART-сниффер

Отдельная диагностическая сборка `samsung-sniffer.yaml`, версия `0.4.7-sniffer`.
Рабочая сборка `samsung-s3.yaml` сохраняет управление и автоматическое разрешение UART.

В тестовой сборке оба UART — **только RX, 9600 8N1**, без внутренних подтяжек.
Нет TX, опросов, ACK, инициализации, MQTT, Modbus и автоматического GitHub OTA.
GPIO17 больше не передатчик. Локальное OTA и Wi-Fi остаются для доступа.
Сохранённые настройки рабочей прошивки не стираются; её веб-пульт временно заменён
страницей захвата. Используются пароли из локального secrets.yaml.

## Подключение

- GPIO18 через свой делитель/согласование: направление основной платы, CN1 №10.
- GPIO17 через отдельный делитель/согласование: обратное направление, CN1 №9.
- Общий GND. На оба RX подавать только согласованный сигнал 3,3 В.
- Для штатного обмена восстановить заводские линии между основной платой и платой дисплея;
  RX подключаются ответвлениями. Никакие два TX не объединять.
- Не загружать рабочую прошивку, пока GPIO17 подключён как пассивное ответвление:
  рабочая прошивка снова назначит GPIO17 выходом TX.

## Запись

`http://10.0.0.15/` показывает принятые порции; `/capture?after=N` возвращает JSON.
Авторизация admin и локальный web_password. GPIO указывает канал, а не доказанный
адрес отправителя. Сохраняются все полученные байты, включая неизвестные/битые пакеты.
Порция завершается на 48 байтах или паузе 20 мс; это НЕ граница протокольного кадра.
Время — миллисекунды обработки ESP32, не точные метки фронтов логического анализатора.
Кольцо 128 порций перезаписывает старые записи; сравнивать oldest_seq с курсором.
Аппаратные переполнения UART не учитываются отдельно, гарантии без потерь нет.
Неподключённый RX может давать шум; данные этого канала не считать штатным обменом.

Запись на компьютер (из корня проекта):

```text
python tools/capture_uart.py --secrets secrets.yaml --seconds 60 --output work/capture.jsonl
```

После перезагрузки boot_id меняется, нумерация порций начинается заново.
Без штатного Wi-Fi и без наших опросов тишина на шине возможна и не доказывает неисправность.

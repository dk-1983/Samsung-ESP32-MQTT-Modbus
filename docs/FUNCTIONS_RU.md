# Справочник функций UART

Цель: Samsung AR24BSFCMWKNER, прямой UART штатного Wi-Fi-модуля, 9600 8N1.
Это реализация найденной карты команд, а не заявление о поддержке всех функций модели.
Полной официальной карты этого интерфейса у нас нет. Значения legacy взяты из
[kumy/samsung-ac](https://github.com/kumy/samsung-ac/blob/7d9df9d8010fe11a8171ebbab044a74d56ee441d/proto/consts.go).

## Основные команды

Веб-климат и MQTT climate предоставляют питание, пять рабочих режимов, температуру
16–30 °C, вентилятор Auto/Low/Medium/High/Turbo, качание Off/Vertical/Horizontal/Both.
В режиме Fan температура не регулируется самим кондиционером.

Preset: None, Boost, Sleep; custom preset: quiet, legacy_smart, legacy_soft_cool,
legacy_wind_1, legacy_wind_2, legacy_wind_3. Последние названия сохранены по исходному
протоколу: это НЕ подтверждённое соответствие современным AI/Eco/WindFree.

Modbus теперь использует [карту MIM-B19N/B19NT](MODBUS.md): питание 52, режим 53,
скорость 54, вертикальное качание 55, температура 58 (×10). Полное качание — 2484,
preset — 2485, полный набор скоростей с Turbo — 2486, Quiet — 2487.
Адреса PDU начинаются с нуля. Старые адреса версии 0.2.0 удалены.

## Расширенные команды

Веб-select/number/button автоматически доступны и через стандартные сущности MQTT ESPHome.
Все записи требуют включённого UART и свежего основного состояния (<10 с).
Новый регистр разрешено испытать без его предварительного успешного чтения: иначе невозможно
исследовать функции, которые начинают возвращать состояние только после первой записи.
В каждый момент разрешена только одна основная либо расширенная команда.

| Индекс | Функция | Группа/регистр | Запись holding | Значения на проводе |
|---|---|---|---:|---|
| 0 | Sleep flag legacy | 12/73 | 2450 | 00 включить, FF выключить; не таймер в часах |
| 1 | Auto clean | 13/32 | 2451 | 22 включить, 23 выключить |
| 2 | Ionizer SPI legacy | 13/75 | 2452 | 0F включить, F0 выключить; наличие ионизатора не предполагается |
| 3 | Energy setting raw legacy | 13/40 | 2453 | 0–255, единицы и применение на нашей модели неизвестны |
| 4 | Reset filter reminder | 13/44 | 2454 | 00, однократное действие |
| 5 | Filter interval legacy | 14/E9 | 2455 | 00/01/02/03/04: upstream 0/180/300/500/700; единицы не подтверждены |
| 6 | Reset usage counters | 14/E8 | 2456 | 01, однократное действие |
| 24 | Airflow direction legacy | 12/63 | 2474 | 12 Legacy off (not accepted on target); 21 Indirect; 31 Direct; 41 Center; 51 Wide; 61 Left; 71 Right; 81 Long; 82 legacy vertical; 92 Vertical; A2 Horizontal; B2 Both; C2 Fixed |

Числа в колонке значений — HEX, кроме явно указанного диапазона 0–255.
Legacy direction не задаёт угол в градусах. 82 конфликтует с подтверждённым на нашем
блоке вертикальным качанием 92, поэтому вынесено отдельно. Если ответ содержит неизвестный
код направления, основное поле swing становится неизвестным; восстановить известный вариант
можно через select Airflow direction legacy или holding 2474, например B2=178.

## Диагностические чтения

Кнопка Read extended Samsung status однократно запрашивает 25 регистров по одному.
Локальный переключатель Extended status polling включает их циклический опрос.
Это только чтение: сбросы, служебные настройки, режимы и Wi-Fi этим не изменяются.
Значения представлены как исходные байты HEX, без выдуманных единиц и кодов ошибок.
Текст `unknown` означает отсутствие ответа, `stale raw ...` — ответ старше 30 секунд.
FC/FE/FF в значении сохраняются буквально; они не объявляются универсальным кодом ошибки.

| Индекс | Поле | Группа/ID |
|---|---|---|
| 7 | Beep raw | 12/74 |
| 8 | Error bytes | 12/F7 |
| 9 | Outdoor temperature raw | 13/76 |
| 10/11 | Cooling/Heating capability raw | 13/77, 13/78 |
| 12 | Power raw | 14/32 |
| 13 | Energy raw | 14/E0 |
| 14 | Runtime raw | 14/E4 |
| 15 | Filter usage raw | 14/E6 |
| 16/17/18 | Main/Panel/Outdoor version | 14/F6, 14/F4, 14/F3 |
| 19 | Model code | 14/F5 |
| 20 | Option code (только чтение) | 14/39 |
| 21 | Control enable | 12/01 |
| 22/23 | WiFi/Internet status raw | 14/37, 14/38 |

Включая управляющие поля 0–6 и 24, это весь каталог 0–24.
Modbus holding 2450+индекс читает однобайтовое значение; многобайтовое/неизвестное/устаревшее
значение возвращает exception 0B. Запись в read-only возвращает 02, неверное значение — 03,
занято/monitor — 06. Расширенная запись допускается только одиночная; смешанные пакеты
и несколько расширенных записей отвергаются целиком до отправки UART.

Input 2481: результат расширенной команды; 2482: индекс последней (255 если нет); 2483: размер каталога (25).
Для каждого индекса есть блок input `2500 + 18*индекс`: слово 0 = длина (1–32),
слова 1–16 = байты попарно big-endian, дополненные нулями; слово 17 = возраст в секундах
(65535 неизвестно). Сырые блоки протухают через 30 с и возвращают 0B, возраст читается всегда.

## Подтверждение и ограничения

Основной Command result и Extended command result разделены. Коды:
0 idle, 1 pending, 2 confirmed, 3 timeout_unconfirmed, 4 cancelled;
для расширенных одноразовых действий 5 acknowledged_unverified.

1205/1305/1405 — ответы на запись: они НЕ обновляют состояние. Для обычной команды
нужно совпавшее последующее чтение/уведомление. Для сброса счётчика даже точное эхо
помечается acknowledged_unverified: факт сброса нужно сверить отдельным чтением счётчика.
Last write reply сохраняет полный ответ для анализа.

UART включён после загрузки. В режиме моста инициализацию и подтверждение
уведомлений выполняет заводская плата; контроллер пересылает их без дублирования.
Для локальных команд нужны свежие разрешение управления и обратная связь.
Отклонённые команды не повторяются автоматически. Служебные кадры не используются
как состояние климата. См. [описание моста](UART_BRIDGE_RU.md).

## Пока не расшифровано

Не добавлены выдуманные команды Display, WindFree, Eco, AI, таймер включения/выключения,
углы жалюзи в градусах, блокировка ИК-пульта, переключатель Beep. Для их реализации нужен
подтверждённый пакет или источник для этого UART-профиля. Эти функции не подменяются
похожими названиями из старого протокола либо регистрами NASA/RS485.

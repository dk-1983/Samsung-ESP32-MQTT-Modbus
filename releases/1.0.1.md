# Samsung-ESP32-MQTT-Modbus 1.0.1

The main web portal now opens in English by default. Select English or Russian
from the navigation on any portal page; the browser remembers the selection for
one year at that controller address. Switching languages reloads the page, so
save form edits first. No controller restart is needed.

Both languages cover the overview, AC controls, MQTT, Modbus, Wi-Fi, Wi-Fi reset,
passwords, updates and system information. Russian remains available. API fields,
MQTT topics, Modbus registers and AC command confirmation are unchanged.

This release retains the startup status-read fix from 1.0.0. The language selector
applies to the main portal on port 80; the advanced ESPHome UI on port 8080 is
unchanged. Clearing cookies or using another browser/address restores English.

## Installation

Use the signed OTA image only on an already provisioned ESP32-S3-WROOM-1 N16R8
controller. This is not a factory image for a blank board. Existing credentials
and persistent transport settings are retained by the OTA update.

## Validation and limitations

The release checks include host protocol/bridge tests, generated-translation and
page-rendering checks, browser tests with simulated API responses in both languages,
and firmware compilation. Simulated browser tests do not replace device testing.
Physical RS485, forced rollback and unverified legacy AC functions retain their
existing validation limitations.

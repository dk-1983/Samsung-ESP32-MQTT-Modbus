# Samsung UART bridge — PCB rev1.0

[English](README.md)

Плата 30 × 48 мм (тот же габарит 48 × 30 мм при повороте), 2 слоя, текущая толщина в KiCad 1,0 мм. Монтаж компонентов с обеих сторон. Без крепёжных отверстий. Основа — электрическая часть Haier pcb-v1.1; файлы Haier не изменены.

## Файлы

- samsung-rev1.0.kicad_pcb — разведённая плата для проверки.
- review/samsung-both-sides.png — обзор обеих сторон, не фотошаблон.
- circuit.json, connections.csv, BOM.csv — актуальные цепи и компоненты этой PCB.
- drc.json — отчёт KiCad; review/pin-check.json — сверка назначений.
- sources/ — воспроизводимые построение, трассировка, заливка, проверки и изображения.

DRC: 0 нарушений и 0 несоединённых цепей. 82 назначения выводов совпали с circuit.json; 25 назначений выводов U1/U2/U3 независимо сверены с исходной схемой Samsung. Аппаратные испытания этой платы не проводились. Gerber и файлы сверловки находятся в production/ вместе с архивом и манифестом контрольных сумм.

## Площадки

Все обозначения MAIN и DISPLAY TX/RX относятся к подключаемой плате Samsung, а не к ESP.

| Площадки | Назначение слева направо, вид сверху |
|---|---|
| TP9–TP12, MAIN | +5V, GND, TX основной платы → делитель → GPIO18; RX основной платы ← GPIO17 |
| TP13–TP16, DISPLAY | +5V, GND, TX дисплея → делитель → GPIO15; RX дисплея ← GPIO16 |
| TP7 / TP8 | RS485 A / B |
| TP1 / TP2 / TP3 | TX0 GPIO43 / RX0 GPIO44 / GND |
| TP4 / TP5 / TP6, снизу | EN / BOOT GPIO0 / 3V3 (контроль напряжения) |

Оба ряда UART — пятачки Ø2 мм, без разъёмов. Питание и GND общие. Штатные цепи Samsung вне UART-моста сохраняются.

RS485: GPIO8 RX, GPIO9 TX, GPIO21 DE и /RE. R6 10 кОм тянет направление к GND. R7 120 Ом и паяная перемычка JP1 включают терминатор A/B. На всех трёх входах RX стоят делители 10/20 кОм. TX выходы ESP прямые, 3,3 В.

## Монтаж и нумерация

Нумерация резисторов/конденсаторов унаследована от платы Haier и отличается от старого Samsung revA PDF. Для сборки использовать BOM.csv и connections.csv именно этой PCB. Соответствия резисторов старой схемы → PCB: R1→R1, R2→R9, R3→R8, R4→R2, R5→R3, R6→R5, R7→R4, R8→R6. Дополнительный R7 PCB — терминатор.

Сохранены обвязка питания исходной платы Haier, LM1117-3.3 SOT-223, ёмкости 220 мкФ и 100 мкФ case C и дополнительные керамические конденсаторы. Это расширенная обвязка относительно старой Samsung revA, где показан C2 47 мкФ без выбранного корпуса. TAB стабилизатора — +3V3; его теплоотводящие полигоны не соединены с GND. Полигоны GND и тепловые переходы ESP отдельные. Зона антенны свободна от меди обоих слоёв.

Плата рассчитана на заводскую металлизацию переходных отверстий, в отличие от самодельной платы вытяжки. Перед заказом проверить механическую посадку и актуальность BOM по имеющимся компонентам. Прошивка, устройства и релизы в этой работе не изменялись.
